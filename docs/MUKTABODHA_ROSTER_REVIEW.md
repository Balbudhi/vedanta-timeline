# Muktabodha tradition and roster review

This document records a first title-level review of the Muktabodha cumulative
catalogue. It is a roster-admission queue, not permission to add every
catalogue label as a thinker or school on the public timeline.

## Nepalese Sarvāmnāya

Muktabodha classifies 23 e-texts under **Nepalese Sarvāmnāya**. This is a real
tradition-level research lane and should be represented in the source library
and eventually in the site’s tradition taxonomy. It is not, on current
evidence, a ready-made list of philosophical authors.

The catalogue is overwhelmingly ritual/manual material: Siddhalakṣmī worship,
*pūjāvidhi*, *paddhati*, *kavaca*, *mantra*, *kriyā*, and festival manuals.
Most records have no named author. The one named author in the initial 23-item
sample is Jagadānanda, attached to a Tripurāsundarī stotra within a composite
manual; that alone does not establish a timeline philosopher entry.

Admission policy:

1. Add the **tradition/source-family** only after its relation to the existing
   Śrīvidyā, Kaula, and Nepalese tantric categories is reviewed.
2. Add an **individual thinker** only where a named author has a serious
   philosophical, exegetical, or theory-bearing text—not merely a catalogued
   ritual manual.
3. Preserve the 23 catalogue records in the source-intake queue even where no
   timeline thinker is added.
4. Begin textual review with *Parātantra* (M00062) and any author-identified
   works; then decide whether a source article, position/tradition entry, or
   thinker entry is warranted.

## High-value Muktabodha matches already confirmed

The cumulative catalogue has direct source matches for existing high-priority
records, including:

- Abhinavagupta: *Īśvarapratyabhijñāvivṛtivimarśinī* (M00020–22),
  *Parātrīśikāvivṛti* (M00154).
- Somānanda: *Śivadṛṣṭi* (M00081).
- Utpaladeva: *Ajaḍapramātṛsiddhi* (M00502), *Īśvarasiddhi* (M00023),
  *Sambandhasiddhi* (M00080).
- Sadyojyotis: *Tattvasaṃgraha* (M00011), *Tattvatrayanirṇaya* (M00012),
  *Nareśvaraparīkṣā* (M00039).
- Aghoraśiva: *Kriyākramadyotikā* (M00126); Śivāgrayogin:
  *Śaivaparibhāṣā* (M00075).
- Pāñcarātra: full two-volume *Ahirbudhnya Saṃhitā* (M00002a–b),
  *Jayākhya Saṃhitā* (M00123), *Lakṣmī Tantra* (M00206), and *Pauṣkara
  Saṃhitā* (M00259).
- Yoga: *Haṭhayogapradīpikā* (M00243).

All are collected only in quarantine. Their catalogue match establishes
availability and licensing—not citation readiness, secure attribution, or a
public thinker entry.

## Initial thinker prospects for review

The catalogue audit found 139 named, non-ritual records not straightforwardly
matched to the current roster. Most require bibliographic disambiguation. The
following are the first worthwhile **review prospects**, because their
catalogue descriptions identify a philosophical or exegetical argument rather
than only ritual procedure:

| Catalogue | Candidate | Why review it | Admission boundary |
|---|---|---|---|
| E00009 | Aiyyaṇācārya, *Matatrayaikyaprakāśikā* | Explicitly compares Śaiva, Vaiṣṇava, and non-dual Vedānta accounts of reality. | Verify author/date and inspect argument before adding a thinker. |
| M00027 / M00513 | Matsyendranātha, *Kaulajñānanirṇaya* / *Kulānanda* | Core Kaula theory-bearing corpus, not merely a ritual title. | Preserve uncertain attribution and distinguish historical Matsyendra from later lineage attributions. |
| M00033 | Śitikaṇṭha, *Mahānayaprakāśa* | Kālīkulakrama system text; catalogue notes a scholarly KSTS witness with Dyczkowski corrections. | Determine whether this is a distinct thinker entry or should be attached to an existing tradition entry. |
| M00510 | Advayavajra/Maitrīpāda, *Advayavajrasaṃgraha* | Catalogue describes short philosophical and yogic tracts on Mahāyāna/Vajrayāna foundations. | Add only after confirming it is not already represented under another identifier. |
| M00269 | Vāmanadatta, *Subodhamañjarī* | Kālīkulakrama work by a named author. | Read the text and establish philosophical scope before admission. |
| M00289 / M00522 | Gorakṣanātha, *Gorakṣamudgara* / *Gorakṣaśataka* | Yoga/renunciation theory with explicit reflective and soteriological content. | Resolve traditional attribution and relation to existing Nātha entries. |
| M00330 | Siddappārādhya, Vīraśaiva *Bhagavadgītā* commentary | Catalogue calls it a Vīraśaiva reading of the Gītā. | Verify date, author identity, and text completeness; a commentary can merit admission if its interpretation is substantial. |
| M00346 | Śrīpati, *Śrīkarabhāṣya* | Directly relevant Vīraśaiva commentary on the *Vedāntasūtra*. | Existing Śrīpati record should receive the witness before any new entry is considered. |

This is deliberately a review list—not an automatic roster expansion. The
next gate is a source packet with the witness, named locus scheme, attribution
posture, and a concise description of the work’s philosophical claims.

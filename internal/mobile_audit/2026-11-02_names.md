# Recognizable names and qualified metadata

Outcome: a reader arriving with another recorded name can identify the correct
thinker, school or work without expanding the main header into a list of badges.

Specification: join explicit school aliases with a slash inside the same school
pill. Use a middle dot only for family/subschool distinctions; omit a repeated
family name already present in the specific name. Never add an “Also called” line.
Short alternate work titles use the same slash within the title; lengthy or
qualified title lists use a native disclosure. A disclosure retains personal names/titles and the full
classification, including parenthetical qualifications. Deduplicate spelling-only
variants. Work cards expose alternate titles separately from associated/constituent
titles. Never promote a negative or contested identification to an unqualified
alias. Existing v2 content gates remain intact. Reader-facing source qualifications
must describe the linked material's scope, not expose stale acquisition instructions.

Search: the existing search surface finds glossary terms, public thinkers and work
titles, with diacritics/punctuation optional and exact names ahead of partial matches.
Results retain the matched qualified name and identify their kind/author. Work
results open the existing work card, without implying a complete translation exists.
The compact names index loads on search demand, not on the timeline critical path;
failure is visible and retryable, and late responses cannot overwrite a closed view.

Implementation order: review existing metadata and regression cases; introduce
shared name selection/normalization and compact build output; integrate profile/work
rendering and search navigation; verify real generated data and browser behavior;
review the scoped diff and deploy. Source/alias review is independent and read-only.
All edits are in an isolated checkout because the user's checkout has unrelated work.

Required checks: real corpus aliases and exclusions; preserved annotations and v2
gates; missing/failed/late index; work navigation and Back; native keyboard disclosure;
mobile/tablet/desktop/large desktop in both themes, text enlargement and wrapping.
Record actual results below before release.

Verification and review (2026-11-02):

- Independent metadata review covered all 189 alternate-title arrays. Constituent
  and companion works are labelled separately; five uncertain equivalences and
  one negative personal identification remain editorial notes. No philosophical
  claims, dates, or Sanskrit translations were rewritten. Three source notes now
  describe the existing translation dossiers without exposing acquisition instructions.
- Independent implementation review found late-index focus loss, loss of full-literal
  search after preview truncation, and focus loss on glossary selection/Retry. All
  were fixed and re-reviewed; no remaining blockers. The real sneha tail-query
  regression failed before the fix and passes afterwards.
- Generated discovery index covers 257 non-hidden records, with only naming fields.
  Tests verify actual corpus aliases, excluded negative identities, family/subschool
  boundaries, constituent-title separation, escaping and existing v2 content gates.
- Real browser: Dvaitadvaita finds Nimbarka; Anandatirtha opens Madhva; Vedanta Sutra
  opens and focuses Badarayana's Brahma-Sutra card. Native disclosure Enter/Space
  works. Exact school glossary buttons work by keyboard. ArrowDown, Enter, Escape
  retain usable focus and Escape returns to the search button.
- A controllable HTTP server returned 503, then delayed a retry: glossary results
  remained available, failure and Retry were visible, and the focused result
  survived names-index arrival. Closed popovers did not regain focus.
- Nimbarka header inspected at 390, 768, 1280 and 1920 CSS pixels, both light and
  dark themes. No new horizontal overflow in the detail content; the full pill
  remains readable. Work-title aliases wrap within the existing card header.
- A temporary local HTML fixture with CSS zoom:2 checked enlarged header text and
  wrapping. This was not a native browser-zoom test (the IAB zoom shortcut had no
  effect). No animation was added; reduced-motion system emulation was unavailable.
- Existing router uses replaceState: Back retains its existing navigation behavior,
  rather than creating a history entry for every selected thinker.

Source qualifications deliberately retain unresolved witness verification. This
release does not certify the broader corpus or settle those source conflicts.
